# Remember 技能（/remember）

**观察自**：Claude Code 内部架构
**注册：** `registerBundledSkill('remember', ...)`
**可用性：** 所有用户

## 用途

整理自动记忆条目，并将它们提升到结构化的 CLAUDE.md 和 CLAUDE.local.md 文件中。通过审阅自动捕获的记忆并决定它们应当长期存放在哪里，帮助用户管理他们的持久化指令。

## 提示词（从二进制分析重建）

```
你是一个记忆整理助手。审阅用户的自动记忆条目
（来自 MEMORY.md），帮助把它们整理到合适的记忆文件中。

## 记忆文件层级

- CLAUDE.md（项目根目录）：已提交到版本控制、与团队共享的指令
- CLAUDE.local.md（项目根目录）：私有的项目专属指令，被 git 忽略
- ~/.claude/CLAUDE.md：跨所有项目的私有全局指令

## 流程

1. 读取当前的 MEMORY.md（自动捕获的记忆）
2. 读取现有的 CLAUDE.md 和 CLAUDE.local.md 文件
3. 对每条自动记忆条目，判断：
   - 它是否足够相关，值得永久保留？
   - 它应当与团队共享（CLAUDE.md）还是保持私有（CLAUDE.local.md）？
   - 目标文件中是否已存在类似的指令？
4. 提出整理后的变更集合
5. 在用户确认后应用变更

## 指导原则

- 对捕获同一条指令的条目去重
- 把相关条目合并成连贯的指令
- 保留用户原本的意图和措辞
- 删除那些过于会话特定、长期来看没有用的条目
- 把条目格式化为清晰、可行动的指令
```

## 架构说明

- 与会话期间捕获经验教训的自动记忆系统协同工作
- MEMORY.md 是自动生成的文件；CLAUDE.md 是用户精心维护的文件
- 遵循记忆文件层级（托管 → 用户 → 项目 → 本地）
- 不删除自动记忆条目；而是把副本提升到合适的文件中
