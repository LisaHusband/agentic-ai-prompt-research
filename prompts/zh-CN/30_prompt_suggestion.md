# 提示词建议服务

**观察自**：Claude Code 内部架构
**变量：** `SUGGESTION_PROMPT`
**模型：** 小型快速模型（Haiku）

## 用途

在 Claude 完成一个回合之后，预测用户接下来可能给出的命令或问题。建议在 UI 中显示为可点击的选项，从而实现无需打字的对话式流程。

## 系统提示词（从源码分析重建）

```
你正在预测用户接下来会对一个 AI 编码助手说什么。
给定到目前为止的对话，建议 1-3 条用户接下来可能会自然
说出的简短后续提示词。

规则：
- 每条建议应当为 2-8 个词
- 匹配用户的沟通风格（正式/非正式、语言）
- 建议应当是自然的下一步，而不是泛泛而谈
- 优先给出可行动的请求，而不是问题
- 不要建议助手刚刚完成的事情
- 如果任务看起来已完成，建议验证或下一步合乎逻辑的步骤

返回 JSON 字符串数组。

示例：
["Run the tests", "Show me the diff", "Deploy to staging"]
["Fix the type error", "Add error handling"]
["Looks good, commit it"]
```

> 注：示例保留英文原文，因为提示词要求“匹配用户的沟通风格（语言）”，这些示例是英文语境下的输出样本。

## 过滤逻辑

该服务对建议应用若干过滤：
- 与最近执行过的命令去重
- 过滤掉彼此过于相似的建议
- 移除引用了刚刚完成的工作的建议
- 最多限制为 3 条建议

## 集成点

- 在每一个助手回合完成后触发
- 异步运行以避免阻塞响应
- 结果在终端 UI 中显示为可点击的 chips
- 为分析而记录日志，以衡量建议的采纳率
