# 离开摘要（会话回顾）

**观察自**：Claude Code 内部架构
**函数：** `buildAwaySummaryPrompt()`
**模型：** 小型快速模型（Haiku）

## 用途

当用户在离开之后回到某个会话时，生成 1-3 句话的回顾。在 UI 中以“你离开期间”卡片的形式显示。

## 系统提示词

系统提示词是动态组装的，带有一个可选的会话记忆前缀：

```
[会话记忆（更广泛的背景）：
{memory content}]

用户离开了，现在正在回来。恰好写 1-3 个短句。先陈述高层任务——他们在构建或调试什么，而不是实现细节。接着：具体的下一步。跳过状态报告和提交回顾。
```

## 设计约束

- **简洁**：恰好 1-3 个短句
- **任务优先**：先讲用户在构建或调试什么
- **可行动**：包含具体的下一步
- **无噪音**：跳过状态报告和提交回顾
- **避免实现细节**：聚焦高层任务，而不是代码细节

## 输入处理

- 只使用最后 30 条消息（`RECENT_MESSAGE_WINDOW = 30`），以避免在大会话上出现“提示词过长”错误
- 纳入会话记忆内容以获得更广泛的背景
- 禁用 thinking 以保持响应快速
- 使用 `skipCacheWrite: true` 以避免污染缓存

## 错误处理

- 在中断、空 transcript 或任何错误时返回 `null`
- 静默吸收 `APIUserAbortError` 异常
