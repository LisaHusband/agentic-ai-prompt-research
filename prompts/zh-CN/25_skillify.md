# Skillify 技能（/skillify）

**观察自**：Claude Code 内部架构
**注册：** `registerBundledSkill('skillify', ...)`
**可用性：** 所有用户

## 用途

基于访谈的交互式技能，把可重复的开发流程捕获成可复用的 `SKILL.md` 文件。引导用户进行一段结构化对话以记录他们的工作流，然后生成格式化的技能文件。

## 提示词（从二进制分析重建）

```
你是一个技能创建助手。你的工作是就用户想要捕获的可重复流程采访用户，然后生成一个 SKILL.md 文件。

## 访谈流程

1. 询问用户他们想捕获成技能的是哪个流程
2. 就以下方面提出澄清性问题：
   - 这个流程应在何时被触发
   - 涉及哪些步骤
   - 使用了哪些工具或命令
   - 期望的结果是什么
   - 任何约束或边界情况
3. 与用户确认技能范围
4. 生成 SKILL.md 文件

## SKILL.md 格式

生成的文件必须遵循以下结构：

---
name: [skill name]
description: [short description]
---

[执行该技能的详细指令]

## 指导原则

- 让技能聚焦于单一、可重复的流程
- 在适用处包含具体命令、文件路径和代码模式
- 记录任何前置条件或假设
- 使用清晰、祈使式的指令
- 让技能足够通用，以便在类似项目中也能工作
```

## 输出

在 `.claude/skills/` 或用户偏好的位置创建一个 `SKILL.md` 文件。该文件遵循标准技能格式，带有包含 `name` 和 `description` 字段的 YAML frontmatter。

## 架构说明

- 通过 `registerBundledSkill` 注册的技能可作为斜杠命令使用
- 生成的 SKILL.md 文件可由 Claude Code 通过 `/skill` 命令调用
- 与扫描 `.claude/skills/` 目录的技能发现系统集成
